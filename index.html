Comando SQL para liberar permissões no Supabase: 
-- Execute no SQL Editor do Supabase para criar e liberar a tabela:
create table if not exists public.events (
  id text primary key,
  date text,
  title text,
  starttime text,
  endtime text,
  duration text,
  category text,
  location text,
  description text
);

grant all on table public.events to anon, authenticated, service_role;
alter table public.events disable row level security;

* O comando disable row level security garante que qualquer pessoa da empresa possa ler e gravar sem erros de bloqueio.
