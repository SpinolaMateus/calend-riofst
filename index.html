Conexão em Nuvem (Supabase)

Sincronize os compromissos em tempo real com todos os colaboradores

Como conectar o seu Supabase gratuitamente:

  1. Acesse supabase.com, crie um projeto e copie o Project URL e a Anon Key (em Project Settings > API).
  2. No SQL Editor do Supabase, execute o código rápido disponível abaixo para criar a tabela.
  3. Cole o URL e a Chave nos campos abaixo e clique em Salvar e Conectar.
Comando SQL para rodar no Supabase (clique para copiar): 
create table if not exists events (
  id text primary key,
  date text,
  title text,
  startTime text,
  endTime text,
  duration text,
  category text,
  location text,
  description text
);
alter table events enable row level security;
create policy "Public Access" on events for all using (true) with check (true);
